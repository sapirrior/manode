# Hello there! Welcome to manode!

Need a hand navigating the world of Node.js documentation? You've come to the right place. manode is your friendly, terminal-based companion for reading manual pages without any of the clutter.

## Quick Start
Ready to dive in? Just type manode followed by the module you're curious about:

*   manode fs --- Explore the content of the File System module.
*   manode path --- Find information about the Path module.
*   manode :list --- List all available documentation modules.
*   manode help --- Bring back this guide anytime.
*   manode help list --- Quick alias to see all available modules.

## Smooth Navigation
Moving around is simple. Use these keys to navigate through the docs:

| Key | What it does |
| :--- | :--- |
| **j** / **Down Arrow** | Move down by one line. |
| **k** / **Up Arrow** | Move up by one line. |
| **Space** / **f** | Scroll down a whole page. |
| **b** | Scroll up a whole page. |
| **g** | Return to the beginning. |
| **G** | Jump to the bottom. |
| **q** | Exit the pager. |

## Pro Tips
*   **Mouse Support**: If your terminal supports it, you can use your scroll wheel or touch screen.
*   **Clean Exit**: Your terminal state will be restored exactly how it was when you press q.
*   **Stay Fresh**: The documentation is included with the package. If you are developing locally, you can run "npm run sync" to update the files in the docs folder.

Have fun exploring, and happy coding!
